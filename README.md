# Sky Turbo
## What is Sky Turbo?
Sky Turbo is a website which can help you to easily flip item in hypixel skyblock.
It combine with Shard Flip , NPC flip ( including some NPC like Miria ) , and Bazaar Flip etc.
You can easily set up the filter to filter the item which volume is too low or the profit is too low.

Is it **AI-slop** ? Yes ! But I think this can help user a lot to find the item which is profitable to flip in hypixel skyblock better than other website.

## How to use Sky Turbo?
For normal user , you can just go to our [website](https://bz.friedturtleee.me) and use it directly.
For developer , you can fork it and run it on your own server. You can also contribute to the project by submitting pull requests or reporting issues.
